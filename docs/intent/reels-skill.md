# 확정된 작업 의도: reels 스킬

- 확정일: 2026-11-22
- 확정 방법: interview-me 인터뷰 후 사용자 명시적 "예"

## 결과

`reels` 스킬 파일을 만들어 `reels.zip`으로 내려받을 수 있게 한다. claude.ai 스킬 메뉴 업로드는 사용자가 직접 한다.

## 스킬이 하는 일

주제만 받으면 아래 순서로 네이버 쇼핑 커넥트용 쇼츠·릴스를 만든다.

1. 필요하면 OpenMontage(OpenMontageInc/OpenMontage) 설치
2. 믿을 만한 출처로 조사 (출처 없는 내용은 "미확인" 표시)
3. A안 고정 형식으로 대본 작성
   - 오해를 깨는 첫 문장 ("○○보다 무서운 건 △△" 식)
   - 원인 설명
   - 숫자로 된 수칙
   - 링크 안내와 광고 표기 ("판매 시 수수료를 받습니다")
   - 45초 안팎
4. 사용자 확인 후 im-not-ai(humanize-korean)로 대본 윤문
5. 맥미니 localhost:7790 "남성1" 음성으로 내레이션
   - 1순위: 맥미니를 세션에 연결해 직접 호출
   - 안 되면: 사용자가 음성 파일을 올림
   - 2026-11-22 변경: 음성 기능을 저장소에 넣었다(`.claude/skills/reels/templates/make_narration.py`, 맥미니 음성 프로그램과 같은 Supertonic 3 남성1). 맥미니 연결 없이 어느 세션에서든 직접 만들고, 음성 때문에 맥미니로 넘기지 않는다.
6. Remotion 기본 틀(templated)로 1080x1920 세로 렌더, 한글 자막, Pixabay 무료 음악
   - 2026-11-22 추가: 영상마다 사용자가 틀을 지정한다. 1번 = Remotion, 2번 = HyperFrames. 지정이 없으면 대본 확인 때 묻는다.
7. 출처 목록과 함께 mp4 전달

## Why

네이버 쇼핑 커넥트용 영상을 매번 같은 방식으로 빠르게 만들기 위해서.

## 완료 기준

- 스킬이 들어 있는 `reels.zip`을 사용자가 내려받는다.
- 스킬 내용을 사용자에게 보여준다.

## 제약

- 3안 제안 없이 바로 A안 형식으로 간다.
- 대본 확인과 음성 단계에서는 매번 사용자 확인을 받는다.
