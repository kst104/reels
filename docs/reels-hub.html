제작 순서

  1. 1준비~/Downloads/reels에서 작업. OpenMontage가 없으면 설치(약 3분), 음성 라이브러리 설치
  2. 2조사한국 정부 → 학회·대학병원 → 해외 공식 기관·논문 순. 확인 안 되면 넣지 않거나 "미확인"
  3. 3대본 확인 ①A형식으로 쓰고 문장마다 출처를 붙여 보여줌. 1번·2번 틀과 화면 방식(글자·움직임·사진) 지정이 없으면 이때 물음
  4. 4윤문 확인 ②im-not-ai(humanize-korean). 내용·숫자·출처 표기는 그대로
  5. 5음성저장소의 음성 스크립트(make_narration.py)로 "남성1"(M1) 직접 생성. 맥미니 음성 프로그램과 같은 Supertonic 3라서 맥미니·클라우드 어디서나 한 세션에 끝냄. 문장 사이 0.6초, 음량 -16 LUFS
  6. 6장면·렌더지정한 틀과 화면 방식으로 렌더(1번 Remotion / 2번 HyperFrames, 글자·움직임·사진), 1080×1920, 한글 자막, Pixabay 음악. 마지막 화면은 광고 표기 카드
  7. 7정리 확인 ③videos/날짜_주제/에 mp4, 대본, 출처, 음성, 자료 저장
  8. 8상품 추천 확인 ④네이버+ 스토어 주간 구매 순위에서 영상 내용과 맞는 상품 중 최상위를 근거와 함께 추천
  9. 9쇼핑 커넥트 링크브랜드 커넥트에서 직접 발급해 붙여 주기(네이버 로그인 필요). 게시 전에 그 상품을 크리에이터샵 겅태의 상점에 먼저 등록
  10. 10인스타그램 게시 확인 ⑤캡션 확인 후 Windsor.ai로 kst1_04 계정에 릴스 게시, 게시 주소 확인 후 네 곳에 기록

고정 규칙

  • 상점 상품은 릴스·유튜브·블로그 모든 콘텐츠와 맞춘다. 콘텐츠가 지워지면 그 상품도 뺀다. 대응표는 깃허브 docs/shop-sync.md이고, 상점에 넣고 빼는 일은 사용자가 한다.
  • 쇼핑 커넥트 링크는 상품마다, 게시물마다 따로 발급해 쓰고 shop-sync.md 링크 표와 caption.md에 적는다. 한 링크를 여러 게시물에 같이 쓰지 않는다.
  • 상점 컬렉션은 블로그·유튜브·릴스 주제별로 나누고, 릴스에서 소개한 상품은 반드시 컬렉션 하나에 넣는다(shop-sync.md 0-1절).
  • 인스타그램 프로필 링크는 크리에이터샵 겅태의 상점으로 고정한다. 영상 끝 멘트는 "소개한 제품은 프로필 링크에서 확인하세요."이다. 소개할 쇼핑 커넥트 상품은 상점에 먼저 등록한 뒤 게시한다.
  • 릴스 3곳은 전 → 제작 → 후 순서로 일하고, 후의 피드백이 다시 전으로 간다: 제작전분석소(남의 쇼츠 분석, 주제 브리프) → 릴스제작소(이 과정) → 제작후분석소(우리 채널 성과 분석, 매일 08:00). 서로의 파일은 읽기만 한다.
  • 영상마다 sources.md에 근거가 된 전 분석 보고서 링크와 제작 요청 프롬프트를 적고, caption.md에 실제 게시한 해시태그를 남긴다.
  • 릴스 작업은 ~/Downloads/reels 폴더에서만 한다.
  • 음성 파일을 사용자에게 따로 만들어 올리라고 하지 않는다.
  • 출처 없는 내용은 넣지 않는다. 해외 통계는 나라를 밝힌다.
  • 마지막 화면에 광고 표기를 넣는다.
  • 렌더 틀은 영상마다 1번(Remotion)·2번(HyperFrames)으로 지정한다. 지정이 없으면 묻는다.
  • 상품은 쇼핑 커넥트에 등록돼 링크가 나오는 것이 1순위, 주간 판매 순위가 2순위다. 후보를 순위 순서로 보여 준다.
  • 상품은 제작 의뢰의 마지막 프롬프트에 맞는 것을 링크에 넣는다. 맞는 상품이 없거나 내용과 잘 맞지 않으면 사용자에게 묻는다.
  • 캡션 광고 표기는 "이 포스팅은 네이버 쇼핑커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다."를 글자 그대로 넣는다. 영상 끝 화면의 광고 표기는 오른쪽 아래에 작게 둔다.
  • 화면 방식도 영상마다 글자·움직임·사진 중에서 묻는다. 사진은 AI로 만들고 출처 목록에 도구와 seed를 적는다.

이 영상은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.
